# src/components/ui/

shadcn/ui primitives (Radix + Tailwind), generated by the shadcn CLI and owned in-repo. Edit freely, but prefer regenerating a component with `npx shadcn@latest add <name>` over hand-porting upstream changes.

Many of these are unused by the app today (calendar, carousel, sidebar, menubar, …). They cost nothing at runtime because Vite tree-shakes them; delete them if their dependencies become a maintenance burden.

`use-toast.ts` here and `hooks/use-toast.ts` are the same shadcn hook; keep them in sync or collapse to one.
